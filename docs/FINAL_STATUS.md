## 建议的解决方案

### 方案 1: 使用 Streamlit 原生图表替代 Pyecharts
将 `st_pyecharts()` 替换为 `st.plotly_chart()` 或 `st.line_chart()`

### 方案 2: 强制重新渲染
在标签页切换时添加 `st.experimental_rerun()` 或使用 session state

### 方案 3: 简化数据
限制显示的数据点数量（如最近 1000 个交易日）

### 方案 4: 分页显示
将大数据集分页显示，减少单次渲染压力
